# 逆襲のフューラーちゃん！
本作品は、ななあし氏によって開発された戦略シミュレーションゲーム  
「ヴァーレントゥーガ」の拡張シナリオです。

## ダウンロード方法
```markdown
### リリース ZIP を使用する

1. [Releasesページ](https://github.com/puppu212/Fuehrer/releases) にアクセス  
2. 最新リリースの **Assets** から ZIP ファイルをダウンロード
```

## 注意事項

```markdown
### 1. Codeボタンや Git clone での取得について

- GitHub の **Code → Download ZIP** や `git clone` でリポジトリを取得すると、  
  `.exe` ファイルは破損します
- Git LFS を使用しても、ユーザーがそのまま実行できる形では取得できません  
- これらの方法でダウンロードしたファイルは使用しないでください
```
